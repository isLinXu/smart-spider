# ADR-0003：采用模态无关的样本契约

## 状态

Accepted

## 背景

SmartSpider 原有的数据集入口以图片分类为中心，但项目同时具备文本、视频、浏览器页面和站点深度采集能力。若继续让目录结构或 `file` 字段代表样本事实，图文对、网页上下文和多轮样本会被迫拆成互相丢失关系的记录。

## 决策

使用 `SampleRecord.modalities` 表达一个样本包含的文本、图片、音频、视频和网页资产，使用 `relations` 表达 `caption-of`、`context-of`、`contains`、`answer-to` 等跨模态关系。

`file` 字段继续保留，仅作为旧图片任务的兼容字段；新的训练入口以 `manifest.jsonl` 为事实来源。

## 结果

### 正面

- 图文样本、纯文本样本和网页上下文可以共用状态库和 manifest；
- 图片分类只是 `task_type` 的一种取值，不再限制数据模型；
- Browser Use、搜索引擎、站点解析器和模型后端可以只负责产出资产或关系；
- 可在不修改旧图片调用方的情况下逐步迁移。

### 负面

- manifest 的 schema 比单一 `file + labels` 更复杂；
- 质量门禁需要按模态和跨模态关系组合；
- 下游训练适配器需要根据 `task_type` 选择输入格式。

## 备选方案

- 每种任务单独定义 JSON schema：短期简单，但无法复用状态、去重和来源证据；
- 只保存原始网页 HTML：保留信息最多，但训练侧需要重复解析，且难以保证可重现。

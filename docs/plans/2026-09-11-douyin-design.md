# 抖音视频采集

新增 Python 抖音模块，支持关键词搜索、视频链接/分享文案和用户主页。
参考 XiaoFeng2233/douyin-spider 的视频 ID、作品列表、作者与时长字段设计；
独立实现，不复制 Java 源码或依赖其旧版 iteminfo 接口。

通过 Playwright 正常加载页面，监听搜索、作品列表与视频详情响应，并解析页面数据岛。
滚动加载在同一页面连续进行，以 ID 去重，限制数量、滚动次数和等待时间。
支持显式导入 Netscape cookies.txt；不自动绕过验证。空结果返回可操作的错误。

发现结果接入 SmartSpider 的 douyin 视频引擎（显式选择，不增加默认浏览器依赖）。
独立 CLI 支持链接和主页，避免把 URL 当作输出目录名称。
有视频直链时通过项目的有界 HTTP 流式下载器下载；无直链时使用现有 yt-dlp。
按 ID 保存视频与元数据，仅文件有效时记成功，临时文件失败清理。

验证：URL 与分享文案解析、数据结构兼容、分页去重、Cookie、失败/超限清理、
CLI 与主流程接线、相关回归测试；真实网络验证单独记录，不能以 mock 代替。

## 关键词实测推进

- “三角洲行动”关键词以目标 10 条进行实测：默认无头 Chromium 和本机 Chrome
  匿名搜索均返回验证码页，未进入下载阶段。
- 新增 `--browser-channel chrome|msedge`，使用本机浏览器的独立临时会话，
  与 `--no-headless --login-wait` 配合供人工验证；不读取日常用户浏览器资料。
- 已执行一次 180 秒人工验证等待，但结束时仍未发现视频，尚不能确认关键词
  批量采集成功。需要确认人工验证后的搜索页状态再继续排查。
- 新增失败诊断文件 `douyin_diagnostics.json`：只记录页面标题、接口路径、状态码
  和解析条数；不记录 Cookie、完整请求查询参数或响应原文。

## 人工验证会话修复

固定 180 秒等待导致用户确认时临时浏览器已退出，无法延续验证状态。
新增 `--wait-for-login`：保留浏览器并持续处理 Playwright 事件，只有终端回车
明确确认后才开始收集；EOF 和关闭浏览器均不视为验证成功。
人工确认模式及错误路径回归通过（抖音模块 34 项测试）。
